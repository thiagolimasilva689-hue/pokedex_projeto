# Análise de Dados Pokémon 🐉

Este projeto utiliza a biblioteca **Pandas** para explorar um dataset completo de Pokémon.

## 📊 O que foi analisado
- Quantos Pokémon existem no dataset?
- Qual a média de ataque?
- Quais são os 5 Pokémon mais rápidos?
- Qual é o Pokémon com maior Total?
- Média de HP por geração.

## 🛠️ Tecnologias utilizadas
- Python
- Pandas
- CSV

## 🚀 Como executar
1. Clone este repositório.
2. Execute o arquivo `teste.py`.
